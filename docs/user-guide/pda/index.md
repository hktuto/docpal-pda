# PDA 使用指南（CN 流程）

本指南逐步指导仓库操作员使用 PDA 完成日常工序，从收货到出库，按实际工作流程顺序编排。每章结构统一：**用途 → 开始之前 → 逐步操作（附截图）→ 常见问题**。

## Part 1 — 入库流程（CN）

| 章 | 内容 | 说明 |
| --- | --- | --- |
| 1 | [手动收货](01-manual-receiving.md) | 无单收货：新增订单号、逐件扫描、完成后自动创建收货单＋上架任务 |
| 2 | [收货扫描](02-receiving-cn-scan.md) | 按 PDF 上传的收货单逐件扫描、标记异常（缺货／损坏／错料）、完成收货 |
| 3 | [上架](03-put-away.md) | 扫货品标签 → 扫货架 → 确认上架 |
| 4 | [临时上架](04-ad-hoc-put-away.md) | 无任务时直接选择品牌/位置扫货上架 |
| 5 | [货架调拨](05-shelf-exchange.md) | 扫源货架 → 扫货 → 扫目标货架搬移 |

## Part 2 — 出库流程

| 章 | 内容 | 说明 |
| --- | --- | --- |
| 6 | [拣货](06-picking.md) | 按分配扫码拣货、装箱、完成拣货（可触发打印） |
| 7 | [待贴标签](07-labeling.md) | 拣货后检查／重印标签、贴好后完成 |
| 8 | [测量](08-measuring.md) | 开箱、扫包裹核实、填写尺寸/重量、确认箱号 |
| 9 | [复核](09-verify.md) | 逐箱重扫复核，扫够数量才能完成 |
| 10 | [查货](10-goods-verify.md) | 每日查货：核对货架异动明细、实地点货、确认 |

## 建议阅读顺序

新员工按流程顺序阅读：1 → 2 → 3 → 6 → 7 → 8 → 9；第 4、5、10 章按需查阅。
