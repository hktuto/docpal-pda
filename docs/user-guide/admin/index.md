# Admin 控制台使用指南

本指南逐步指导办公室文员／仓库主管使用 Admin 控制台处理日常单据与仓库主数据，章节按实际工作流程顺序编排。每章结构统一：**用途 → 开始之前 → 逐步操作（附截图）→ 常见问题**。章节名称与左侧导航菜单的实际名称一致。

## Part 1 — 日常运营（按单据流程顺序）

| 章 | 内容（= 菜单名称） | 说明 |
| --- | --- | --- |
| 1 | [收货单](01-receiving-orders.md) | 列表筛选、详情页单项/批次修改（Date Code／Lot／COO／COW／箱号）、确认收货、重新分配、下载出货单 |
| 2 | [客户收货上传](02-receiving-cn-upload.md) | 上传客户收货 Excel／PDF → 本地核对 → 建立 CN 收货单（PDA「手動收貨／收貨掃描」的单据来源） |
| 3 | [拣货单](03-picking-orders.md) | 列表筛选、修改交货日期/date code、下载拣货清单、重新分配（单单重分配，不影响其他单） |
| 4 | [新增 VMI](04-vmi-upload.md) | Excel 批量建立 VMI 拣货单：本地核对、问题清单、一次性建立 |
| 5 | [取消发票](05-cancel-records.md) | 跟进上游取消：登记替代发票、点击「確認退回上架」放行 PDA 退回任务 |
| 6 | [问题与警示](06-issues.md) | 收货问题、拣货问题、过期日期码警告、问题回报（bug 收件箱） |

## Part 2 — 主数据设定

| 章 | 内容 | 说明 |
| --- | --- | --- |
| 7 | [仓库设定](07-warehouse-setup.md) | 货架（QR 打印、Excel 导入导出）、货架箱（批量建立）、子库（共享组）、箱型、国家 |
| 8 | [库存查询](08-stock-search.md) | 多条件搜寻库存、批次历史异动；附「臨時上架」与「內部調撥單」两个只读查询页 |

## 建议阅读顺序

新同事按流程顺序阅读：2 → 1 → 3 → 6；第 4、5 章按需查阅；第 7、8 章属设定与查询，需要时再阅读。
