# Folder Cabinet

**選單路徑：** Client → Browse → Folder Cabinet

![Folder Cabinet 畫面](../assets/client-06-folder-cabinet.png)

## 此畫面的用途
以團隊由實體檔案記錄沿用下來、熟悉的檔案櫃及資料夾結構來整理文件。

## 你可以在此做甚麼
- 瀏覽各個檔案櫃及其下的資料夾
- 開啟按檔案櫃結構整理的文件

## 誰會使用
習慣以檔案櫃、抽屜及資料夾思維工作的檔案管理人員及一般用戶。
