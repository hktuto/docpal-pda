# User Menu / 產品導覽

DocPal 的視覺化導覽，完全對照實際線上選單。DocPal 設有兩個網站：一個是**面向用戶的客戶端網站**，讓用戶每天尋找、分享及處理文件；另一個是**管理網站**，讓管理員設定用戶、內容結構、工作流程及系統設定。以下每一頁展示一個選單畫面——它的外觀、你可以做甚麼，以及誰會使用它。客戶端右上角的頭像下拉選單有獨立一頁：[[client/19-account-menu|Account Menu]]。

| 選單 | 頁面 | 你會看到 |
|------|------|-------------------|
