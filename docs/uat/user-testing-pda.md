# PDA 應用程式 — 用戶驗收測試（UAT）

本文件是 Warehouse PDA 應用程式（`apps/web`，Android PDA 或瀏覽器）的用戶測試腳本，供測試人員逐項執行並記錄結果。管理後台的測試請參閱 [user-testing-admin.md](./user-testing-admin.md)。

功能細節可對照 [PDA 用戶指南](../app-docs/user-menu/index.md) 及各 [Flow 文件](../app-docs/flows/index.md)。

## 測試準備

- 後端服務已啟動（:3002），示範種子資料已載入。
- 測試帳號：`operator` / `DocPal2026!`（操作員）；如需兩人情境，請管理員在後台另建一個操作員帳號。
- 每輪測試開始前，可在頁首 **⋮ 選單 → 重設資料庫** 還原示範資料。
- 建議在實機（Android PDA，硬件掃描器）上執行；標明「需硬件掃描器」的個案在瀏覽器可用鍵盤輸入代替。
- 部分個案需要管理員在後台配合操作（標明「需後台配合」）。

## 結果記錄

每項個案在「結果」欄填寫 **通過 / 失敗 / 不適用**，失敗時在「備註」欄記錄實際情況及截图。
