# Admin 管理後台 — 用戶驗收測試（UAT）

本文件是 Warehouse Admin 管理後台（`apps/admin`，桌面瀏覽器）的用戶測試腳本，供測試人員逐項執行並記錄結果。PDA 應用程式的測試請參閱 [user-testing-pda.md](./user-testing-pda.md)。

功能細節可對照 [Admin 後台用戶指南](../app-docs/admin-user-menu/index.md)。

## 測試準備

- 後端服務已啟動（:3002），後台運行於 :3100（或部署網址），示範種子資料已載入。
- 測試帳號：`admin` / `DocPalAdmin2026!`（admin 群組成員才能登入後台）。
- 每輪測試開始前，可呼叫 `POST :3002/dev/reset` 或在 PDA ⋮ 選單重設資料庫，還原示範資料。
- 部分個案需要 PDA 配合操作（標明「需 PDA 配合」）。
- 後台直接修改主檔及訂單資料，沒有二次確認以外的安全網 — 測試刪除/移除個案時請使用測試建立的資料。

## 結果記錄

每項個案在「結果」欄填寫 **通過 / 失敗 / 不適用**，失敗時在「備註」欄記錄實際情況及截图。
