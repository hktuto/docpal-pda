# Admin order reset — implementation plan (2026-11-07)

Spec: `docs/superpowers/specs/2026-11-07-admin-order-reset-design.md`. UAT: `docs/uat/features/CR-050.json`.

1. **Backend picking reset.** Extract the per-package reversal core of `removeScannedPackage` into `reverseScannedPackageTx` (unguarded; callers keep their own guards). Add `resetPickingOrderProgress(db, {orderId, actorId})` in `apps/backend/src/db/picking.ts`: 404 / 409 shipped guard, reverse + delete every package, unbox foreign packages in the order's boxes, delete `shipping_box_items` + `shipping_boxes` (verify tasks cascade), zero `picking_items.picked_qty`/`status`, order → `pending` with lock / labeling / label-printing / shipped / issue columns cleared, audit + SSE. Route `POST /admin/picking-orders/:id/reset` in `apps/backend/src/routes/admin/flowEdits.ts`.
2. **Backend CN reset.** `resetCnOrder(db, batchNo, actor)` in `apps/backend/src/db/receivingCn.ts`: 404 / 409 clear guard, clear scan columns + zero progress columns on all invoice items, delete scan events + the CN put-away task, order → `pending` with arrival stamps cleared, audit + SSE. Route `POST /admin/receiving-cn/orders/:batchNo/reset` behind the `cnReceiving()` guard in `apps/backend/src/routes/admin/receivingCn.ts`.
3. **Admin UI.** `resetPickingOrder` / `resetCnOrder` wrappers in `apps/admin/utils/flowApi.ts`; Reset order buttons on `apps/admin/pages/picking-orders/[id].vue` (hidden when shipped) and `apps/admin/pages/receiving-cn/[batchNo].vue` (hidden when clear), both `window.confirm` → call → `load()` + `logsKey.value++`; i18n keys in all three locales.
4. **Tests.** `apps/backend/src/routes/admin/orderReset.test.ts`: picking — 404, 409 shipped, happy path (packages/boxes/verify task gone, picked_qty 0, allocations kept + restored, lot stock restored, reverse ledger rows, audit row); CN — 404, 409 clear, happy from `scanning` (scan columns cleared, events + task deleted, order pending), plus `in_hand` resets.
5. **Docs/tracker.** This spec + plan, `docs/uat/features/CR-050.json`, regenerate `docs/uat/UAT-Test-Tracking.xlsx` via `node scripts/gen-uat-xlsx.mjs`.
6. **Verify.** `pnpm --filter @warehouse/backend build` + full backend test suite (`docker compose up -d` first).
