# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `@nuxtjs/i18n` support for `en-US`, `zh-CN`, and `zh-HK` (default `zh-HK`) while keeping English URLs and translating all static UI, status labels, and error messages.

**Architecture:** Add `@nuxtjs/i18n` with `strategy: 'no_prefix'` and a small `i18n/config.ts`. Keep locale messages in `i18n/locales/*.ts` (copied from the pre-translated plan artifacts). Introduce `I18nError`, `useErrorMessage`, and `useStatusLabel` helpers so DB codes surface as localized text. Wire a `<LanguageSwitcher>` into `AppHeader` and persist the choice to `localStorage`.

**Tech Stack:** Nuxt 3, Vue 3 Composition API, `@nuxtjs/i18n`, PGlite, Capacitor.

---

## File structure

| Path | Purpose |
|------|---------|
| `i18n/config.ts` | `vueI18n` options: composition API, fallback locale. |
| `i18n/locales/en-US.ts` | English messages (copied from plan artifact). |
| `i18n/locales/zh-CN.ts` | Simplified Chinese messages (copied from plan artifact). |
| `i18n/locales/zh-HK.ts` | Traditional Chinese (Hong Kong) messages (copied from plan artifact). |
| `composables/i18nError.ts` | `I18nError` class carrying a translation code. |
| `composables/useErrorMessage.ts` | Maps `I18nError` codes to `t('errors.<code>')`. |
| `composables/useStatusLabel.ts` | Maps DB status codes to `t('status.<domain>.<code>')`. |
| `composables/useLocalePreference.ts` | Reads/writes `warehouse-locale` from `localStorage`. |
| `components/LanguageSwitcher.vue` | Dropdown to switch locale. |
| `components/AppHeader.vue` | Adds the switcher; translates aria-labels and confirm text. |
| `layouts/default.vue` | Applies saved locale on mount. |

### Task 5: Create `useErrorMessage`

**Files:**
- Modify: `composables/errorMessage.ts`

- [ ] **Step 1: Replace the file content**

```ts
import { I18nError } from "~/composables/i18nError";

export function useErrorMessage() {
  const { t } = useI18n();

  return function errorMessage(e: unknown): string {
    if (e instanceof I18nError) {
      return t(`errors.${e.code}`, (e.params ?? {}) as Record<string, unknown>);
    }
    if (e instanceof Error) {
      return e.message;
    }
    return String(e);
  };
}
```

### Task 7: Create `useLocalePreference`

**Files:**
- Create: `composables/useLocalePreference.ts`

- [ ] **Step 1: Write the composable**

```ts
const STORAGE_KEY = "warehouse-locale";
const SUPPORTED_LOCALES = ["en-US", "zh-CN", "zh-HK"] as const;
type SupportedLocale = (typeof SUPPORTED_LOCALES)[number];

export function useLocalePreference() {
  const { locale, setLocale } = useI18n();

  function restore() {
    const saved = localStorage.getItem(STORAGE_KEY);
    if (saved && SUPPORTED_LOCALES.includes(saved as SupportedLocale)) {
      setLocale(saved as SupportedLocale);
    }
  }

  function persist(code: SupportedLocale) {
    localStorage.setItem(STORAGE_KEY, code);
  }

  watch(locale, (code) => {
    persist(code as SupportedLocale);
  });

  return {
    restore,
    persist,
  };
}
```

<script setup lang="ts">
const route = useRoute();
const router = useRouter();
const { t } = useI18n();
const { logout: authLogout } = useAuth();
const pg = useNuxtApp().$pglite;

const title = computed(() => (route.meta.title as string) || t("meta.warehouse"));
const showBack = computed(() => route.path !== "/");

function goBack() {
  if (window.history.length > 1) {
    router.back();
  } else {
    navigateTo("/");
  }
}

function logout() {
  authLogout();
  navigateTo("/login");
}

async function resetDb() {
  if (!confirm(t("appHeader.resetConfirm"))) return;

  if (pg) {
    await pg.close();
  }

  const dbName = "/pglite/warehouse-demo-pglite";
  await new Promise<void>((resolve, reject) => {
    const req = indexedDB.deleteDatabase(dbName);
    req.onsuccess = () => resolve();
    req.onerror = () => reject(req.error);
    req.onblocked = () => resolve();
  });

  localStorage.clear();
  window.location.reload();
}
</script>

## String-to-key quick reference

The source-of-truth for keys is the locale files in `docs/superpowers/plans/i18n-locales/`. When migrating a file, locate the English string in the `en-US.ts` file to find its key, then replace the literal with `$t('key')` in templates or `t('key')` in scripts.

Common patterns:

- Page titles: `meta.<page>` or `<flow>.detail.title`.
- Buttons: `actions.<verb>`.
- Status badges: `useStatusLabel().<domain>(code)`.
- Errors: `throw new I18nError('<code>', params)` + `useErrorMessage()`.
- Reason labels: `reportIssueModal.reasons.<code>` and `picking.issueReasons.<code>`.
- Country names: `countryLabels.<value>`.
